 Titanic Passenger Risk & Survival Prediction

A machine learning project focused on predicting passenger survival outcomes from the Titanic dataset using data preprocessing, exploratory data analysis, feature engineering, and supervised learning techniques.

The project demonstrates an end-to-end machine learning workflow, from raw passenger data to model evaluation and survival prediction.

Project Overview

The Titanic disaster is a classic machine learning problem used to understand how passenger characteristics influenced survival outcomes.

This project analyzes features such as:

Passenger class

Age

Sex

Number of siblings/spouses aboard

Number of parents/children aboard

Passenger fare

Port of embarkation

The objective is to build classification models that predict whether a passenger survived or did not survive.

 Objectives

Perform exploratory data analysis (EDA)

Identify patterns and relationships within passenger data

Handle missing and inconsistent data

Perform feature engineering

Encode categorical variables

Train supervised machine learning models

Compare model performance

Evaluate classification results

Build a reusable prediction workflow
